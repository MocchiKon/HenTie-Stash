Downloads with gallery-dl

hitomi and e-hentai/exhentai are downloaded by gallery-dl. Its status and updates are below the Save button.

When unchecked, the copy shipped with the app is used (there is none for macOS). Check this to use your own gallery-dl from the system PATH instead.

e-hentai account (exhentai subscriptions)

exhentai shows its search only to a logged-in account, so an exhentai subscription sends your e-hentai account's cookies with each search. Copy them from your browser while you are logged in to e-hentai: open its developer tools (F12), then Storage (Firefox) or Application (Chrome), Cookies, e-hentai.org. They are kept in this app's database, like the nhentai API key, and sent only to e-hentai's own sites. Downloads still read the cookies of the browser chosen above.

One of exhentai.org's own cookies. Without it the app gets one from exhentai the way your browser did; give it when exhentai still refuses the account.

Image Compression

Applies to images you add by hand — creating a chapter, or uploading into an existing one — and is what the Download page starts at; a download can still pick another mode per paste. Your own modes are managed from the Manage page.

When unchecked, the copies of ImageMagick, cjxl, djxl and avifenc shipped with the app are used. Check this to use your own magick, cjxl, djxl and avifenc from the system PATH instead.

Some browsers cannot display JPEG XL, so pages encoded to it are decoded to PNG on the way out. Automatic checks what this browser supports and decodes only when it has to. On chrome you might need to enable the flag chrome://flags/#enable-jxl-image-format and on firefox image.jxl.enabled.

ComfyUI

Show pages in the image viewer through your own ComfyUI workflows - upscaling, restoration, edits with diffusion models. The files in the data folder are never changed. How to set up ComfyUI and export workflows for the app is described in COMFYUI.md.

Where ComfyUI answers. http://127.0.0.1:8188 is ComfyUI's own default; the ComfyUI desktop app uses port 8000.

A folder in ComfyUI's user folder (ComfyUI/user/default/ in most installations) holding workflows exported with File → Export (API). Its subfolders are listed too.

Temporary files

Leave a folder blank to choose automatically: on Linux a RAM disk is used when one is found with enough free space - for download staging only when the download is compressed - and otherwise a folder inside the data folder. The app keeps its files in a folder of its own inside the folder you choose (hentie-…, holding staging, work, transcoded and comfyui) and never touches anything else there, so one folder can serve all four. Files already in a folder are not moved when you change it. On Windows, pointing the two caches at a RAM disk keeps the largest files the app writes off your SSD.

Shut down

Stops the app for everyone using it. Pages still loading get up to a minute to finish, and a download still running a few seconds; one that does not finish runs again the next time the app starts. Pressing Ctrl+C in the app's console window does the same. Closing that window also stops the app, but Windows then gives it only a few seconds.
