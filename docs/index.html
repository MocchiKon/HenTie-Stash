Features

Built for a local collection.

Browsing, storage, downloads and automation, without leaving the app.

Browse

Search and read your collection.

Search titles, tags, artists and characters. Filter and sort a large library, and review a backlog one result at a time. The reader works on a phone as well as a desktop.

Matching

Chapters find their series.

New chapters match an existing series by title, artist and native title. New families are created on their own.

Subscriptions

Follow an artist.

Save a search and check it on a schedule. New work is queued automatically; anything you already own is skipped.

ComfyUI

Use your own workflows.

The image viewer can send pages through any ComfyUI workflow with an image input and an image output.

Any image-in, image-out workflow works. Results are cached; the files in your data folder are not modified.

ComfyUI is a separate program and must be running while you use a workflow. About ComfyUI

  1. 01

    Upscale

    Run any upscale model installed in ComfyUI.

  2. 02

    Descreen

    Remove screentones from scanned pages.

  3. 03

    Decensor

    Use an AI workflow to redraw censored areas.

  4. 04

    Translate

    Render translated text onto the page.
