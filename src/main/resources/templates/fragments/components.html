gallery-dl

These sources are downloaded by gallery-dl.

e-hentai/exhentai galleries are downloaded with the e-hentai account from Settings.

e-hentai/exhentai only, hitomi never serves the originals. Unticked: the resampled image (usually 1280 px wide, or your account's "Image Size" setting), 1 point of your image limit per page. Ticked: the original file. It needs the e-hentai account from Settings (without it the resampled image is used), costs 1 point plus 1 per 0.1 MB of the file (a 3 MB page costs 31), and can cost GP. The limit then runs out much sooner, and downloads fail with "Image limit exceeded" until it recovers or you reset it on e-hentai.

error

A number, or a range for a random wait, e.g. 0.4-0.65. e-hentai/exhentai: the wait before each request for an image page (--sleep-request; it replaces gallery-dl's own 3-6 seconds). hitomi: the wait before each image download (--sleep). Too low a value can get your IP temporarily banned (e-hentai bans for "excessive pageloads").
